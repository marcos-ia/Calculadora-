Widget para iPhone y Mac

Puedes ver tus hábitos del día directamente en la pantalla de inicio de tu iPhone, iPad o el Escritorio de tu Mac utilizando la aplicación gratuita Scriptable.

Pasos para configurarlo:

  1. Descarga la app gratuita Scriptable desde el App Store en tu iPhone o Mac.
  2. Abre Scriptable, toca en el icono + para crear un nuevo script y pégale el código de abajo.
  3. Añade un widget de Scriptable en tu pantalla de inicio y selecciona este script.
CÓDIGO PARA SCRIPTABLE (JS) 
// Widget para Scriptable (iOS / macOS) - AetherHabit
let widget = new ListWidget();
widget.backgroundColor = new Color("#0f172a");

let title = widget.addText("🔥 AetherHabit");
title.textColor = new Color("#6366f1");

widget.addSpacer(8);

let progressText = widget.addText("Progreso de Hoy: 4/4 completados (100%)");
progressText.textColor = new Color("#f8fafc");
progressText.font = Font.systemFont(12);

widget.addSpacer(6);

let habit1 = widget.addText("✅ Meditación Mañanera");
habit1.textColor = new Color("#10b981");
habit1.font = Font.systemFont(11);

let habit2 = widget.addText("✅ Ejercicio Físico");

Script.setWidget(widget);
Script.complete();
widget.presentSmall();

Widget de Pantalla para iPhone y Mac

Puedes ver tus hábitos del día directamente en la pantalla de inicio de tu iPhone, iPad o el Escritorio de tu Mac utilizando la aplicación gratuita Scriptable.

Pasos para configurarlo:

  1. Descarga la app gratuita Scriptable desde el App Store en tu iPhone o Mac.
  2. Abre Scriptable, toca en el icono + para crear un nuevo script y pégale el código de abajo.
  3. Añade un widget de Scriptable en tu pantalla de inicio y en las opciones del widget selecciona este script.
CÓDIGO PARA SCRIPTABLE (JS) 
// Widget para Scriptable (iOS / macOS) - AetherHabit
let widget = new ListWidget();
widget.backgroundColor = new Color("#0f172a");

let title = widget.addText("🔥 AetherHabit");
title.textColor = new Color("#6366f1");
title.font = Font.boldSystemFont(16);

widget.addSpacer(8);

let progressText = widget.addText("Progreso de Hoy: 4/4 completados (100%)");
progressText.textColor = new Color("#f8fafc");
progressText.font = Font.systemFont(12);

widget.addSpacer(6);

let habit1 = widget.addText("✅ Meditación Mañanera");
habit1.textColor = new Color("#10b981");
habit1.font = Font.systemFont(11);

let habit2 = widget.addText("✅ Ejercicio Físico");
habit2.textColor = new Color("#10b981");
habit2.font = Font.systemFont(11);

let habit3 = widget.addText("⏳ Lectura (20 págs)");
habit3.textColor = new Color("#94a3b8");
habit3.font = Font.systemFont(11);

Script.setWidget(widget);
Script.complete();
widget.presentSmall();
